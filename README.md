## 📖 Sobre

O **samsung-voice-cmd** é um projeto que desenvolvi para controlar a minha **TV Samsung** por meio de **comandos de voz**. 📺

Foi criado como aplicativo **Android** e desenvolvido diretamente no **AIDE**, a IDE para programar Android no próprio celular. 📱

---

## 🛠️ Tecnologias

- 🤖 **Android**
- 🧰 **AIDE** (ambiente de desenvolvimento)
- 🎙️ **Comandos de voz**

---

## ⚖️ Aviso

Este é um projeto **independente** e **não é afiliado** à Samsung.
